## Question

What is the typographic scale?

- Raleway weights to keep (300–700 are loaded today), and whether to add a second family or a mono font.
- Named steps (display, h1–h4, body, body-sm, caption, label, button) with size, line height and weight, for mobile and desktop.
- The minimum font size (`text-xs` is used 413 times).
- How headings are applied: utility classes, a `Text`/`Heading` component, or `@tailwindcss/typography` for rich content.

Link a rough specimen prototype in `prototypes/`.

The named steps are delivered as static Tailwind `fontSize` entries, not CSS variables ([How tokens are structured](04-token-architecture.md)).

## Assets

- Prototype: [prototypes/type-scale.html](../prototipos/type-scale.html). Switch variants with `?variant=A|B|C` or ← →, and switch mobile/desktop with the width buttons (`?w=mobile`):
  - **A, Compact:** 14px body.
  - **B, Comfortable:** 16px body.
  - **C, Two densities:** 14px UI text plus a 16px `prose` step for reading, and an 800-weight marketing display.

  Each variant shows a specimen of every named step, an admin screen, a student reading a question, and the home hero. Colors are the decided palette.

## Resolution

Decided in a prototype session on 2026-10-28 by reacting to [prototypes/type-scale.html](../prototipos/type-scale.html). **Variant C ("Two densities")** won. The table below is the final scale, and it matches the prototype's C, except that `overline` is 12px at every width.

| Step (class `text-<step>`) | Mobile → desktop (`sm` = 768px) | Line height | Weight | Extra |
|---|---|---|---|---|
| `display` | ~~36 → 60px~~ **30 → 48px** *(amended in [Expressive layer for the home page](14-home-expressive-layer.md))* | ~~1.05~~ **1.1** | 800 | `letter-spacing: -0.01em`; home/marketing section titles. The home hero uses the exception step `text-hero` (48 → 72 → 96px), defined in that ticket |
| `h1` | 24 → 30px | 1.2 | 700 | |
| `h2` | 20 → 24px | 1.25 | 700 | |
| `h3` | 16 → 18px | 1.3 | 600 | |
| `h4` | 14 → 16px | 1.4 | 600 | |
| `prose` | 16 → 17px | 1.7 | 400 | long-form reading: question statements and alternatives, study materials, news, rich text |
| `body` | 14px | 1.5 | 400 | default UI text (tables, forms, cards, menus) |
| `body-sm` | 13px | 1.45 | 400 | metadata, secondary lines |
| `caption` | 12px | 1.4 | 500 | **the minimum size** |
| `label` | 13px | 1.3 | 600 | form labels |
| `button` | 14px | 1 | 600 | |
| `overline` | 12px | 1.3 | 700 | `text-transform: uppercase; letter-spacing: 0.16em` (eyebrows) |
| `numeric` | 24 → 28px | 1.1 | 700 | `font-variant-numeric: tabular-nums` (KPI figures) |

- **Two densities.** 14px is the UI body (it keeps today's `text-sm` density across the 679 dash uses). A separate 16–17px `prose` step serves long reading, especially students on phones. A 14px-everywhere scale and a 16px-everywhere scale were both rejected.
- **Font loading:** Raleway **400, 500, 600, 700, 800 upright + 400 italic** (6 files, down from 10 in `index.html`). Weight 300 is dropped (`font-light`/`font-thin` uses map to 400). `font-black` (900) maps to 800. 800 is added because the 53 `font-extrabold`/`font-black` uses (mostly `homeV2`) intended it and currently render at 700.
- **Minimum size is 12px.** The 23 uses below it (`text-[10px]`, `text-[11px]`, `text-[9px]`) move to `caption`. Arbitrary `text-[Npx]` sizes are banned in new code by the guard test.
- **Delivery:** each step is **one class**, generated by a small plugin in `tailwind.config.js` that bundles size, line height, weight and tracking and emits the desktop values inside `@media (min-width: 768px)`. Authors never write breakpoint prefixes for type. Fluid `clamp()` and hand-written `text-h1-mobile sm:text-h1` pairs were both rejected. This stays within "static values in the Tailwind config" ([How tokens are structured](04-token-architecture.md)).
- **Application: classes only, no `Text`/`Heading` component.** Authors write the semantic element with a step class (`<h2 className="text-h2">`; a visually small but semantic heading is `<h2 className="text-h4">`). shadcn `CardTitle`/`DialogTitle`/`SheetTitle` get their step baked in. Rich content (tiptap, markdown, question statements, materials) uses `@tailwindcss/typography`'s `prose`, configured to the `prose`/`h*` steps and palette tokens. V1 `Text` (60 files, renders a `<div>` with no heading semantics) and MUI `Typography` (26 files) retire.
- **Tailwind's default `fontSize` scale is deprecated** (`text-xs`…`text-9xl`, ~1,744 uses), under the same policy as the legacy colors: existing uses keep working, the guard test blocks new ones and ratchets the count down, and migration rewrites them. The weight classes `font-normal`/`medium`/`semibold`/`bold`/`extrabold` **stay allowed** for emphasis inside a step. `font-thin`/`font-light`/`font-black` are flagged, since those weights aren't loaded.
- **Monospace** (8 `font-mono` uses: code and IDs) uses the system mono stack. No webfont is added.
